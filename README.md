🏠 Room Allotment System

The Room Allotment System is a simple Python-based command-line application designed to allocate rooms to students efficiently. The system automatically assigns the next available room to each student and maintains a record of occupied rooms.

It ensures organized room distribution and prevents over-allocation once all rooms are filled. After the allocation process, the system displays the final room assignments along with the list of occupied rooms.

This project demonstrates practical implementation of data structures and basic control flow concepts, making it ideal for beginners learning structured problem-solving in Python.

✨ Key Features

Automatic room allocation

Prevents assignment when rooms are full

Tracks occupied rooms

Displays final allotment summary

Simple and structured logic

🛠 Technologies Used

Python 3

Dictionary (for room management)

Set (for tracking occupied rooms)

Loops and conditional statements
